# calvinhancock.com

Portfolio site for Calvin W. Hancock, served by GitHub Pages at [calvinhancock.com](https://calvinhancock.com).

## Layout

| Path | What it is | Live URL |
|---|---|---|
| `index.html` | Portfolio home page | `/` |
| `resume.pdf` | Resume, linked from the home page | `/resume.pdf` |
| `SPOKEN/` | Voice-dictated Vertex: English-like code you can speak and run | `/SPOKEN/` |
| `NEFS/` | Build your own featural script, starting from Tessera | `/NEFS/` |
| `SYNTAX/` | Syntax Tree Sandbox: drag-and-drop constituency parsing | `/SYNTAX/` |
| `SEER/` | SEER assembly editor (not linked from the home page yet) | `/SEER/` |
| `CNAME` | Custom domain for GitHub Pages | — |

Each project is a single self-contained `index.html` with no build step. To add a project, create a folder with its own `index.html` and `README.md`, then add a card to the `#projects` section of the root `index.html`.
