# SEER

Public SEER assembly editor for the SEER custom CPU.

Write SEER assembly (or C, compiled by the SEER LLVM backend) and run it on a simulator.
This page only edits text: the assembler, simulator, control-flow compiler and register
allocator run on the SEER service (`/run` and `/compile`), so none of them ship to the browser.

Live: https://calvinhancock.com/SEER/
