      Assembly guide — how to write the Source box
      

      
The basics

      
    
        
  • One instruction per line: mnemonic  op1, op2, op3. Mnemonics are not case-sensitive. Operands are separated by commas.
    • 
        
  • Comments start with ; or # and run to the end of the line.
    • 
        
  • A line ending in : is a label. In plain assembly it is only a marker for you: branches cannot name a label. (Use the control-flow checkbox below, which works out the jumps for you.)
    • 
        
  • Numbers: 42, -5, 0x2A, 0b101010, 'A'. An out-of-range value is an error, not silently cut.
    • 
        
  • Compiler output works as-is. You can paste the assembly from llc -mtriple=seer straight in: directive lines (starting with .) are ignored, and an operand like target@pcrel is replaced by the byte distance to that label. Source without either is left untouched.
    • 
        
  • Every instruction is 4 bytes, except nop hlt sei cli sysret ebreak ecall wfe, which are 1 byte. End your program with hlt.
    • 
      


      
Registers

      
    
        
  • r0 … rN, where N is set by the “Register depth” slider (it must match the hardware). Using a register at or above the depth traps.
    • 
        
  • zr always reads 0, and writes to it are thrown away. It is the one register that exists at any depth.
    • 
        
  • Aliases sp, fp, ra are the top registers below zr (depth−2, −3, −4). They are only names; prefer plain rN.
    • 
        
  • Registers are not cleared on reset. Set a register before you read it. The simulator warns when you don't.
    • 
      


      
Instruction cheat sheet

      

        
KindFormInstructions

        
3-register ALUop rd, rs1, rs2add sub mul div mod and or xor nand nor xnor sll srl sra; eq and slt (signed) give 0 or 1. There is no unsigned compare-to-register; use jltu/jgeu.

        
Immediate ALUop rd, rs, imm8addi subi muli andi ori xori nandi nori xnri eqi slti slli srli srai. The imm8 is signed, −128..127 (up to 255 is accepted and read as signed).

        
Constantsli rd, valueli takes 0..65535 or −128..−1. For bigger values, build them: li r1, 0x1234 / slli r1, r1, 16 / li r2, 0x5678 / or r1, r1, r2.

        
Bit tricksop rd, nbset bclr bflp btst rol ror work on rd itself with a bit number or rotate count 0..63. bswap rd, w and brev rd, w take a width of 8/16/32/64. popcnt rd, rs and clz rd, rs count bits.

        
Loadld64 rd, cap, ptr64-bit load. ld.s32 loads 32 bits and sign-extends.

        
Storests64 rs, cap, ptr64-bit store. sts32 stores 32 bits. The value comes first, then the address registers.

        
Capabilitycgetroot rd, csetaddr cd, cs, rs, csetbounds cd, cs, rs …See “Memory” below. Also cincaddr candperm cmove ccleartag cget{addr,base,top,len,perm,type,tag}.

        
Branchjeq rs1, rs2, offjeq jne jlt jge (signed) and jltu jgeu (unsigned). Taken when the comparison holds. Written by hand, off is a connector-node offset, not a label (see below).

        
Call / returnjmp off, ra / retret is jmp 0, which pops the hardware return stack.

        
One bytenop hltnop is also a connector node: the only kind of place a jump can land.

      

      
Not run by the simulator (they assemble, but a run stops there): floating point, csel, bext bins bperm pdep pext clmul crc32 bfly.


      
Memory: you need a capability first

      
With capabilities on (the normal mode), every load and store goes through a capability register holding a range of memory. Make one from the root, point it at an address, then shrink it to the size you want. Reads and writes outside it trap with 0x82.


cgetroot   r3            ; r3 = root capability
li         r4, 0x1000
csetaddr   r3, r3, r4    ; address = 0x1000
li         r4, 0x100
csetbounds r3, r3, r4    ; r3 = [0x1000, 0x1100)
li         r1, 1234
sts64      r1, r3, zr    ; mem[0x1000 + 0] = 1234
ld64       r2, r3, zr    ; r2 = mem[0x1000 + 0]

      
The third register is the byte offset (use zr for 0). Accesses must be aligned: 8 bytes for ld64/sts64, 4 for the 32-bit ones. Data memory is 16 KB. You can keep a capability itself in memory with csc/clc.


      
Control flow: switch on “Use control-flow abstraction”

      
Plain assembly branches go through a table of connector nodes (nops) that must be registered by hand with wrctrl, and a branch names a table slot relative to the number of nops crossed so far. That is tedious and easy to get wrong, so for anything with a loop, an if or a function, tick the checkbox under Settings and write this instead. Indentation (4 spaces) shows what is inside what; ordinary instruction lines still work between the blocks.

      

        
WriteMeaning

        
if a < b: / elif …: / else:Condition is reg OP reg, with OP one of == != < >= > <= or the unsigned <u >=u >u <=u. Registers only, so load constants into a register first.

        
while a != zr:Loop while the condition holds.

        
loop:Loop forever; leave with break.

        
break / continueLeave or restart the innermost loop.

        
def name(): / call name() / returnFunctions take no arguments; pass values in registers. Define them at the top level, in any order, and call only functions that exist (no function pointers). They share all registers, so the caller sees what the callee leaves behind.

        
retry N: / onfail: / succeed / break NNeed the “retry/succeed/onfail” checkbox. Run a body up to N times; leave several loops at once.

        
use rN: / call f() lend rNNeed the “use/lend” checkbox. Only allow a capability register to be used inside the block, and hide it from a callee.

      

      
In this mode the compiler adds a setup section at the start (connector-node registration, and a stack capability that uses r1–r3 and r11). So don't expect r1–r3 to be 0 at the start of your code, and ra is written by calls. If you don't end with hlt, one is added. The top-level lines (outside any def) are the main program. The byte-edit boxes in the output are turned off.


li   r1, 5
li   r10, 0
while r1 != zr:
    add  r10, r10, r1      ; r10 = 5+4+3+2+1
    subi r1, r1, 1
call double()
hlt                        ; r10 = 30

def double():
    add r10, r10, r10
    return


      
Symbolic register names

      
Tick “Use symbolic register names” (together with control flow) and write any name instead of rN; registers are picked and released for you. A name must be written to before it's read, and names only stand in for registers, not for numbers.


li   count, 5
li   total, 0
while count != zr:
    add  total, total, count
    subi count, count, 1
hlt


      
Reading the result

      
Assemble shows the bytes of each line, colored by field (hover for what each byte is). Run simulation reports the final non-zero registers and whether it halted. Send & verify runs the same program on the board and compares the registers.

      bitstream and a register depth of 64 or more. Stops after the iteration count or duration, whichever
